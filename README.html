RadioKit 📻

Unified Radio Streaming for Swift

Overview

RadioKit is a premium Swift package built for modern radio streaming applications. It abstracts the complexities of multiple radio APIs into a single, elegant interface.

Unified

One model, multiple sources. Search Radio Browser and Eclipse simultaneously.

Safe

Actor-based architecture ensures thread-safety for state and networking.

Modern

Strictly leverages Swift 6 concurrency, iOS 17+, and macOS 14+ features.

Quick Start

Initialize the actor and start discovering stations in seconds.

import RadioKit

let client = RadioClient(userAgent: "MyRadioApp/1.0")

// Prepare the client
await client.discoverServers()

// Search for stations
let results = try await client.search(query: "Jazz")
